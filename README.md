## pephorror | thoughts & code ##
Esta es mi página web personal, inspirada en algunos de los sitios de blogs más populares. Aquí expondré algunas de mis ideas y proyectos, e intentaré, de vez en cuando, dejar recomendaciones musicales interesantes.
# 
El archivo *editor.html* es un editor offline para añadir, eliminar o editar entradas de blog del archivo principal. Lo edito en offline en mi dispositivo y luego actualizo el código en *Gihub Pages*.
# 
Eres libre de descargarte los archivos y jugar con ellos para crear tus propias versiones para tu sitio web personal.
